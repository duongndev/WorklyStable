# WorklyStable

WorklyStable là một ứng dụng quản lý chấm công, nghỉ phép, làm thêm cho nhân viên và admin được xây dựng bằng React Native.

# Tính năng

### Nhân viên
- Chấm công
- Xin nghỉ phép
- Đăng ký làm thêm
- Xem thông báo hệ thống

### Admin
- Quản lý chấm công
- Quản lý nghỉ phép
- Quản lý làm thêm

# Yêu cầu hệ thống

- Node.js (>= 22.11.0)
- Ruby (để sử dụng CocoaPods cho iOS)
- React Native CLI
- Android Studio (dành cho phát triển Android)
- Xcode (dành cho phát triển iOS)

# Hướng dẫn Cài đặt

1. **Cài đặt các thư viện phụ thuộc (Dependencies):**
   ```bash
   npm install
   ```

2. **Cài đặt thư viện cho iOS (CocoaPods):**
   ```bash
   cd ios && pod install && cd ..
   ```

# Chạy Ứng dụng

### Khởi động Metro Bundler
```bash
npm start
```

### Chạy trên Android
```bash
npm run android
```

### Chạy trên iOS
```bash
npm run ios
```
